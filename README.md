# Семейный бюджет

Веб-приложение для учёта семейных доходов, расходов и финансовой цели. Сайт открывается как набор HTML-страниц: приветственный лендинг и рабочий калькулятор.

Данные хранятся в браузере (`localStorage`) и никуда не отправляются.

## Как открыть

1. Скачайте или откройте папку проекта.
2. Запустите `index.html` в браузере (двойной щелчок или «Открыть с помощью»).
3. На главной странице нажмите **Открыть калькулятор**.

Рабочая страница калькулятора: `app.html`.

## Что умеет калькулятор

- добавление доходов и расходов по категориям;
- сводка: доходы, расходы, остаток, доля расходов;
- финансовая цель и прогресс по положительному остатку;
- краткий анализ бюджета;
- редактирование и удаление операций;
- светлая и тёмная тема;
- экспорт в CSV для Excel;
- очистка всех данных.

## Структура репозитория

```
index.html      главная страница
app.html        калькулятор
css/styles.css  общие стили
js/app.js       логика калькулятора
js/theme.js     тема на лендинге
archive/        исходные версии HTML
```

## Локальная разработка

Отдельный сервер не нужен. Если браузер ограничивает локальные файлы, откройте папку через любой статический сервер. На Windows PowerShell:

```powershell
Start-Process index.html
```
